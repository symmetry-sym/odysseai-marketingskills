# 营销技能工具箱

本 skill 将原项目的专业模块收纳为一个入口。先阅读 [模块索引](references/module-index.md)，选择最贴近用户目标的一个主模块；只有任务确实跨领域时才组合多个模块。

## 工作方式

1. 根据用户目标、业务阶段、渠道和交付物选择主模块。
2. 完整读取 `references/modules/<模块名>/guide.md`，并按需读取该模块目录内的 `references/`、运行其 `scripts/` 或复用其 `assets/`。
3. 模块指南提到另一个营销 skill 时，不寻找顶层 skill；回到模块索引，读取相应的内部模块指南。
4. 缺少业务信息时先做能安全推进的部分，只询问会实质改变方案的关键问题。
5. 广告发布、邮件发送、账户变更和付费操作仍需用户在动作发生前明确授权。

不要一次加载全部模块。普通写作、编程或非营销分析不应触发本 skill。
